三星 Galaxy Store 审核被拒的原因，是“默认语言”那一栏

Justin Lee, Dumb Game Lab · 2026-11-15

在三星 Galaxy Store 上架、销售地区不止一个国家的应用，默认名称和描述必须是英语。我把默认语言设成了韩语，提交《只活一次：人生模拟器》，11月11日收到 Test Confirmation Rejected。在此之前，我已经走完了付费卖家审批（申请 4 次）和首次提交时的年龄分级栏陷阱。后来我换成英文名称、英文描述和 6张 英文截图重新提交；另一款设置相同的游戏，我直接取消了审核，改成英语默认后重新提交。

卖家审批 4 次，然后才轮到提交

在 Galaxy Store 上传应用之前，要先通过卖家审批。我 10月21日 第一次申请转为付费卖家，11月10日 第4次申请 才通过。每次被拒的原因都一样：企业编号（D-U-N-S）资料里看不到网站。

审批一通过，我马上上传了《只活一次：人生模拟器》1.0.7。这一步还有个坑：年龄限制有两个选择栏，其中一个是针对中国的隐藏栏，填在那里会显示“保存完成”，提交却被拦下。找到真正的那一栏、选了 12+ 之后，列表里才出现 Ready for Review。

被拒原因：默认名称和描述不是英语

提交之后，状态变成了 Test Confirmation Rejected。拒绝原因要点开列表里评审一栏的图标，打开附件（Report.html）才能看到。只有一行：“[Metadata] Default description and application name (Not in English)”。

它没说应用会崩溃，也没说违反了政策。我创建应用时把默认语言选成了 Korean，而销售地区在两个以上，所以默认名称和描述必须是英语。我原本觉得“韩语游戏就该默认韩语”，这个想法是错的。

  • 状态：Test Confirmation Rejected
  • 原因：Default description and application name (Not in English)
  • 根源：默认语言一栏是 Korean

我的修改：默认语言改成英语，韩语作为“添加语言”

修改步骤是这样的：先在添加语言里加上 English，再把默认语言改成 English，然后用英语重写名称、描述和一句话简介。英文名称我定为“One Life: Reborn Simulator”，韩语保留为附加语言。

截图是按语言分别上传的，所以我在英语栏里重新上传了 6张 英文截图。最后一步：状态为“评审失败”的应用文件不能原样再提交，我在文件标签页里删除了同一个 APK，再重新添加。版本号没变，直接通过了。

设置相同的另一款游戏，我提前改了

当时还有一款游戏在审核中。“Trigger Trio”的默认语言也是韩语。我知道它肯定会因为同样的原因被拒，就没等结果，直接取消了审核，改成英语默认后重新提交。取消后状态会退回“注册中”，所以还能修改。

注册流程文档的第一行，我也把“默认语言 Korean”改成了“English”（#6643）。以后新游戏一开始就用英语。

一个看了会笑的理由，花了我两天

卖家审批花了 3周，年龄分级栏的坑占了一次，语言一栏花了 两天。在打开被拒邮件之前，我一直怀疑是应用体积或权限的问题。原因其实只有一行，可找到这一行的路径，就藏在列表图标的里面。

两款游戏现在都在等待审核。写这篇文章的时候，我还不知道有没有通过。有结果之后，我会补充到这篇文章里。

FAQ

Galaxy Store 的默认语言应该选什么？

销售地区在两个以上时，默认名称和描述必须是英语。第一次注册应用时，把默认语言选成 English，韩语用“添加语言”加上，这样更稳妥。

Test Confirmation Rejected 是什么意思？

表示审核被拒。具体原因要点开列表里评审一栏的图标，打开附件（Report.html）才能看到。问题不一定出在应用本身，也可能是名称、描述这类注册信息。

被拒之后，能用同一个 APK 重新提交吗？

可以。状态为评审失败的文件不能原样再提交，需要在文件标签页里删除该 APK，再把同一个文件重新添加，我这边版本号没变，直接通过了。

截图也要单独上传英文版吗？

要。截图是按语言分别上传的。把默认语言改成英语之后，英语栏要重新补 4~8张 截图（我传了 6张）。
