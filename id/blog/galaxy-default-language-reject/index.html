Game saya ditolak Galaxy Store gara-gara satu kolom: bahasa default

Justin Lee, Dumb Game Lab · 2026-11-15

Hanya Satu Kehidupan

Main di browser

Kalau aplikasi dijual di dua negara atau lebih di Samsung Galaxy Store, nama dan deskripsi default harus berbahasa Inggris. Saya membiarkan bahasa default tetap Korea saat merilis «Satu Hidup: Simulasi Kehidupan», dan pada 11 November statusnya jadi Test Confirmation Rejected. Itu terjadi setelah 4 kali pengajuan seller berbayar dan jebakan kolom usia di pengajuan pertama. Saya kirim ulang dengan nama, deskripsi, dan 6 tangkapan layar berbahasa Inggris. Satu game lain dengan setelan yang sama saya batalkan dari antrean review, lalu saya kirim ulang dengan bahasa default Inggris.

4 kali pengajuan seller, baru setelah itu upload

Di Galaxy Store, sebelum bisa upload aplikasi kamu harus lolos persetujuan seller dulu. Saya pertama kali mengajukan peralihan ke seller berbayar pada 21 Oktober, dan baru disetujui pada pengajuan keempat, 10 November. Alasan penolakannya selalu sama: profil nomor bisnis (D-U-N-S) tidak menampilkan situs web.

Begitu disetujui, saya langsung upload Satu Hidup versi 1.0.7. Di tahap ini pun ada jebakan. Ada dua kolom pembatasan usia di layar, dan salah satunya kolom tersembunyi untuk China. Kalau nilainya diisi di sana, penyimpanan tampak «selesai» tapi pengajuan tertahan. Saya baru bisa maju setelah menemukan kolom yang benar dan mengisi 12+, lalu muncul Ready for Review di daftar.

Alasan ditolak: nama dan deskripsi default bukan bahasa Inggris

Setelah pengajuan, statusnya berubah jadi Test Confirmation Rejected. Alasan penolakan hanya terbaca kalau kamu klik ikon di kolom review pada daftar, lalu buka file lampiran (Report.html). Isinya satu baris: «[Metadata] Default description and application name (Not in English)».

Bukan soal aplikasi crash atau melanggar kebijakan. Saat membuat aplikasi, saya memilih bahasa default Korean, padahal karena negara penjualannya dua atau lebih, nama dan deskripsi default harus berbahasa Inggris. Anggapan saya salah: game Korea, jadi bahasa defaultnya Korea.

  • Status: Test Confirmation Rejected
  • Alasan: Default description and application name (Not in English)
  • Penyebab: kolom bahasa default masih Korean

Perbaikannya: bahasa default jadi Inggris, bahasa Korea lewat «tambah bahasa»

Urutan perbaikannya begini. Tambahkan English lewat tambah bahasa, ubah bahasa default jadi English, lalu tulis ulang nama, deskripsi, dan deskripsi singkat dalam bahasa Inggris. Nama Inggrisnya saya tetapkan «One Life: Reborn Simulator». Bahasa Korea tetap ada sebagai bahasa tambahan.

Tangkapan layar diunggah terpisah untuk tiap bahasa, jadi saya mengunggah 6 tangkapan layar berbahasa Inggris yang baru di kolom English. Terakhir, file aplikasi yang berstatus «review gagal» tidak bisa dikirim begitu saja. Di tab file, saya hapus APK yang sama lalu menambahkannya lagi. Nomor versinya lolos tanpa diubah.

Game lain dengan setelan sama saya perbaiki duluan

Saat itu masih ada satu game lagi yang sedang direview. Trigger Trio juga memakai bahasa default Korea. Hampir pasti ditolak dengan alasan yang sama, jadi saya tidak menunggu hasilnya: review saya batalkan, bahasa default saya ganti ke Inggris, lalu saya kirim ulang. Setelah dibatalkan, statusnya kembali ke tahap pendaftaran sehingga masih bisa diedit.

Baris pertama dokumen prosedur pendaftaran juga saya ubah dari «bahasa default Korean» jadi «English» (#6643). Untuk game berikutnya, saya mulai dari bahasa Inggris sejak awal.

Dua hari habis untuk alasan yang bikin tertawa kalau dibaca

Persetujuan seller makan 3 minggu, jebakan kolom usia satu, dan kolom bahasa dua hari. Sebelum membuka email penolakan, saya curiga ke ukuran aplikasi atau izin akses. Alasan aslinya cuma satu baris, tapi jalan menuju baris itu tersembunyi di dalam ikon pada daftar.

Kedua game sekarang menunggu review. Saat tulisan ini dibuat, saya belum tahu apakah lolos. Kalau hasilnya sudah keluar, akan saya tambahkan di tulisan ini.

FAQ

Bahasa default Galaxy Store sebaiknya apa?

Kalau dijual di dua negara atau lebih, nama dan deskripsi default harus berbahasa Inggris. Saat pertama kali mendaftarkan aplikasi, pilih English sebagai bahasa default, lalu tambahkan bahasa Korea lewat tambah bahasa. Itu cara yang lebih aman.

Apa arti Test Confirmation Rejected?

Artinya review ditolak. Alasannya baru terbaca kalau kamu klik ikon di kolom review pada daftar, lalu buka file lampiran (Report.html). Penyebabnya bisa saja bukan aplikasinya, tapi informasi pendaftaran seperti nama dan deskripsi.

Setelah ditolak, apakah bisa kirim ulang dengan APK yang sama?

Bisa. File berstatus review gagal tidak bisa dikirim begitu saja, jadi hapus APK itu di tab file lalu tambahkan file yang sama lagi. Dengan cara ini, nomor versinya lolos tanpa diubah.

Apakah tangkapan layar juga harus diunggah terpisah dalam bahasa Inggris?

Ya. Tangkapan layar diunggah terpisah untuk tiap bahasa. Begitu bahasa default diubah ke Inggris, kolom English harus diisi lagi dengan 4 sampai 8 gambar (saya memakai 6).
