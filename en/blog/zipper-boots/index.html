Zipper Started as a Name for Boots

The name “zipper” came from a rubber boot brand in 1923

Justin Lee, Dumb Game Lab · 2026-11-14

Short answer Zipper was originally a name for rubber boots in 1923. The fastener ended up taking the name.

You pull zippers up and down several times a day. But “zipper” wasn’t originally the name of this little device.

So what was it called?

In 1893, American inventor Whitcomb Judson patented a device. He called it the Clasp Locker. It fastened shoes without laces.

In 1913, Gideon Sundback made it sturdier and began selling it. This time, the name was “Hookless Fastener.”

In 1923, the American company B.F. Goodrich attached the fastener to rubber boots. One quick pull was all it took to close them.

ZIPthe sound of something moving quickly

Goodrich named those boots “Zipper.” But people started using the name for the fastener instead of the boots.

So the fastener stole the boots’ name

Zippers beat buttons on trouser flies in 1937. That was when French designers embraced zippers for men’s trousers.
