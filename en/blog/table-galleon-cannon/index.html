Fact #44

The table decoration has a cannon?

This ship-shaped table ornament packed a clock, moving figures and an automatic cannon

Justin Lee, Dumb Game Lab · 2026-11-24

Short answer A late-16th-century mechanical ship ornament contained a clock, figures, music and an automatic cannon. A later working model recreated the bang with gunpowder.

A fancy ship for the dining table. The artifact pictured here is a mechanical ship ornament from the late 16th century.

It contained a clock, moving figures and a musical mechanism. It originally moved on wheels, too.

How many features does a table decoration need?

An automatically fired little cannon was fitted at the front.

A museum in the Netherlands later built a working model of this kind of ship. That model is separate from the original artifact in the photo.

The model recreated the cannon's bang using real gunpowder. The museum says demonstrations even required a firearms permit.

I said put a ship on the table, not start a naval battle.
