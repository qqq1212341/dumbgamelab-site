GPS Satellite Clocks Are Set Slow on Purpose

GPS satellites go up with their clocks set wrong on purpose

Justin Lee, Dumb Game Lab · 2026-10-24

Short answer Because of relativity, GPS satellite clocks run 38 microseconds fast each day. So before launch, they're set to run slow on purpose.

Your map app knows where you are thanks to GPS satellites. They circle the Earth in very high orbits.

Each satellite carries a precise clock and keeps sending time signals. Your phone measures distance by how long a signal takes to arrive.

So if a clock is off by even a tiny bit, your location ends up way off.

This is where Einstein comes in. According to relativity, time doesn't flow at the same speed everywhere.

Moving fast slows time down. Because of this, satellite clocks fall behind by about 7 microseconds a day.

Where gravity is weaker, time speeds up. Up that high, satellite clocks gain about 45 microseconds a day.

+38μsboth added up: how much faster the satellite clock runs each day

38 millionths of a second is nothing, right?

Light travels about 300 m in 1 microsecond, so 38 microseconds is about 11 km. For GPS, which measures distance using time, that's a big difference.

So before launch, GPS satellite clocks are set to run slow by that much on purpose. Relativity is at work in your directions every day.
