확인 방법

게임 비교 글은 이렇게 확인합니다

Justin Lee, Dumb Game Lab · 2026-10-30

덤게임랩의 «같은 게임 찾기» 글은 스토어 페이지를 읽는 데서 끝나지 않고, 목록에 든 게임을 업무폰에 직접 설치해 켜 본 결과를 싣습니다. 설치 크기, 첫 실행 시간, 비행기 모드에서 켜지는지, 처음 뜨는 동의·권한 창을 재고 화면은 우리가 찍은 것만 씁니다. 재지 못한 칸은 «스토어 페이지 기준만 확인»이라고 따로 적습니다.

이 글의 순서

  1. 왜 직접 켜 보나
  2. 어떤 폰으로 확인하나
  3. 한 게임을 재는 순서
  4. 재지 못하는 것
  5. 화면과 문구에 대한 약속
  6. 글쓴이와 문의

왜 직접 켜 보나

«오프라인 가능»은 스토어 설명에 흔히 적힌 말이지만, 실제로 비행기 모드에서 첫 화면까지 가는지는 게임마다 다릅니다. 시작 화면에서 동의 창을 띄우고 서버에 접속하지 못해 멈추는 게임도 있습니다.

그래서 비교 글에 넣는 게임은 폰에 깔아 같은 순서로 켜 봅니다. 순위를 매기려는 게 아니라, 고르는 사람이 설치 전에 궁금해하는 칸(크기, 인터넷 없이 되는지, 광고·결제 창이 언제 뜨는지)을 숫자와 화면으로 채우려는 것입니다.

어떤 폰으로 확인하나

덤게임랩 업무용 안드로이드 폰(삼성 갤럭시 Z플립5, SM-F731N, 안드로이드 14)에 Wi-Fi를 연결해 확인합니다. 소리와 진동은 꺼 둔 채로 하고, 광고 맞춤 설정 같은 개인 설정은 건드리지 않습니다. 글마다 확인 날짜와 기기를 맨 위에 적습니다.

한 게임을 재는 순서

게임마다 아래 순서를 같게 따릅니다.

  • Google Play 에서 설치합니다. 설치 버튼이 «구매»이거나 계정 가입이 먼저 필요하면 건너뛰고 «스토어 페이지 기준만 확인»으로 표시합니다.
  • 설치된 파일(APK)의 크기 합계를 잽니다. 처음 켠 뒤 추가 데이터를 내려받는 게임은 실행 뒤 앱 크기를 따로 적습니다.
  • 홈 화면에서 앱을 처음 켜서 화면이 뜨기까지 걸린 시간을 잽니다.
  • 약 100초 동안 켜 둡니다. «계속», «동의» 같은 안전한 버튼과 화면에서 색으로 찾은 큰 확인 버튼만 가볍게 누르고, 알림 권한 창은 허용하지 않고 닫습니다. 약관을 끝까지 내려야 하는 창이나 닉네임 입력은 넘기지 않습니다. 이때 화면을 캡처합니다.
  • 비행기 모드를 켠 채 앱을 다시 실행해 65초 동안 지켜봅니다. 게임 화면까지 가는지, 연결 오류나 로딩에서 멈추는지, 첫 설정·동의 화면에서 멈추는지를 화면으로 판정합니다.
  • 확인이 끝나면 앱을 지웁니다.

재지 못하는 것

처음 10분 동안 광고가 몇 번 뜨는지는 아직 재지 못합니다. 도입부를 짧게 지나가는 확인이라 광고가 나오기 전에 끝나는 게임이 많기 때문입니다. 광고 칸은 스토어 페이지에 적힌 «광고 포함»과 인앱 결제 표시를 그대로 옮기고, 그렇다고 적습니다.

결제가 필요한 게임, 가입이 먼저인 게임, 지역 제한이 있는 게임도 직접 켜 보지 못합니다. 그런 게임은 글 안에서 «스토어 페이지 기준만 확인»으로 구분됩니다.

화면과 문구에 대한 약속

다른 회사 게임의 화면은 우리가 위 폰에서 직접 찍은 것만 씁니다. 스토어에 올라온 이미지를 가져다 붙이지 않습니다.

가격과 광고 표시는 날짜가 지나면 바뀝니다. 글의 수정일은 가격이나 표시가 실제로 바뀌어 고쳤을 때만 올리고, 무엇을 고쳤는지 글 아래 «바뀐 내용»에 한 줄 남깁니다.

우리가 만든 게임이 목록에 들어가면 «Dumb Game Lab 게임»이라고 표시하고, 약한 점도 같은 칸에 같은 비중으로 적습니다.

글쓴이와 문의

글은 덤게임랩 운영자 Justin Lee 가 확인하고 씁니다. 회사 소개와 언론 보도는 소개 페이지에 있습니다. 틀린 값이 보이면 info@dumbgamelab.com 으로 알려 주세요. 확인해서 고치고 바뀐 내용에 남깁니다.

FAQ

비행기 모드에서 켜진다는 건 어떤 기준인가요?

비행기 모드를 켠 상태로 앱을 다시 실행했을 때 65초 안에 게임 화면(튜토리얼이나 첫 플레이 화면)이 뜨면 «켜짐», 연결 오류 안내나 로딩 막대에서 멈추면 «안 켜짐», 약관·닉네임 같은 첫 설정 화면에서 멈추면 «첫 설정·동의 화면에서 멈춤»으로 적습니다. 마지막 경우는 게임이 오프라인으로 되는지 알 수 없다는 뜻입니다.

설치 크기는 어떻게 재나요?

Google Play 에서 설치한 뒤 기기에 놓인 APK 파일의 크기를 모두 더합니다. 처음 켠 뒤 추가 데이터를 받는 게임은 실행 뒤 앱 크기를 따로 표시합니다.

광고 횟수는 왜 안 나오나요?

처음 10분 동안의 광고 횟수는 짧은 확인으로 신뢰할 만한 숫자를 얻기 어려워 재지 않습니다. 대신 스토어 페이지의 광고·인앱 결제 표시를 날짜와 함께 적습니다.

얼마나 자주 다시 확인하나요?

월 1회 가격과 표시를 다시 읽고, 바뀐 칸이 있을 때만 글을 고치고 수정일을 올립니다.
