갤럭시 스토어가 게임을 반려한 이유는 «기본 언어 칸»이었다

Justin Lee, Dumb Game Lab · 2026-11-15

한 번뿐인 인생

웹에서 하기

삼성 갤럭시 스토어에 두 나라 이상에 파는 앱을 내면 기본 이름과 설명이 영어여야 합니다. 나는 기본 언어를 한국어로 두고 «한 번뿐인 인생»을 냈다가 11월 11일에 Test Confirmation Rejected 를 받았는데 유료 판매자 승인에 네 번, 첫 제출의 연령 칸 함정까지 지나온 뒤였습니다. 영어 이름·설명·스크린샷 6장으로 다시 냈고 같은 설정이던 다른 게임 한 편은 심사를 취소하고 영어 기본으로 다시 냈습니다.

판매자 승인에 네 번, 그다음 제출

갤럭시 스토어는 앱을 올리기 전에 판매자 승인부터 받아야 합니다. 나는 10월 21일에 유료 판매자 전환을 처음 신청했고 11월 10일 네 번째 신청에서 승인을 받았는데 반려 사유는 번번이 사업자 번호(D-U-N-S) 프로필에 웹사이트가 안 보인다는 것이었어요.

승인이 나자 바로 한 번뿐인 인생 1.0.7을 올렸습니다. 이 단계에서도 함정이 하나 있었어요. 연령 제한을 고르는 칸이 화면에 둘 있었는데 하나는 중국용 숨은 칸이었고 그쪽에 값을 넣으면 저장은 «완료»인데 제출이 막혔습니다. 진짜 칸을 찾아 12+로 넣고서야 목록에 Ready for Review 가 떴습니다.

반려 사유: 기본 이름·설명이 영어가 아니다

제출 뒤 상태가 Test Confirmation Rejected 로 바뀌었습니다. 반려 사유는 목록의 리뷰 칸 아이콘을 눌러 첨부 파일(Report.html)을 열어야 읽힙니다. 한 줄이었어요. «[Metadata] Default description and application name (Not in English)».

앱이 죽는다거나 정책을 어겼다는 말이 아니었습니다. 나는 앱을 만들 때 기본 언어를 Korean 으로 골랐고 판매 국가가 두 곳 이상이라서 기본 이름과 설명이 영어여야 했던 것입니다. 한국어 게임이니 한국어가 기본이라는 내 생각이 틀렸어요.

  • 상태: Test Confirmation Rejected
  • 사유: Default description and application name (Not in English)
  • 원인: 기본 언어 칸이 Korean

고친 것: 기본 언어를 영어로, 한국어는 «언어 추가»

고치는 순서는 이렇습니다. 언어 추가에서 English 를 넣고 기본 언어를 English 로 바꾸고 이름과 설명과 한 줄 소개를 영어로 다시 씁니다. 영어 이름은 «One Life: Reborn Simulator» 로 했어요. 한국어는 추가 언어로 남겼고요.

스크린샷은 언어마다 따로입니다. 그래서 영어 칸에 영어 화면 6장을 새로 올렸습니다. 마지막으로 «리뷰 실패» 상태의 앱 파일은 그대로 못 내서, 파일 탭에서 같은 APK 를 지우고 다시 추가했는데 버전 번호는 그대로 통과했습니다.

같은 설정이던 다른 게임은 미리 고쳤다

그때 심사 중이던 게임이 하나 더 있었어요. 트리거 트리오도 기본 언어가 한국어였습니다. 같은 이유로 반려될 게 뻔해서 결과를 기다리지 않고 심사를 취소했고 영어 기본으로 바꿔 다시 냈습니다. 취소하면 상태가 등록 중으로 돌아가서 고칠 수 있었어요.

등록 절차 문서의 첫 줄도 «기본 언어 Korean» 에서 «English» 로 고쳤습니다(#6643). 다음 게임부터는 처음 만들 때 영어로 시작합니다.

사람이 읽으면 웃는 이유로 이틀을 썼다

판매자 승인에 3주, 연령 칸 함정에 하나, 언어 칸에 이틀이었습니다. 반려 메일을 열기 전까지는 앱 용량이나 권한 문제를 의심했어요. 원문은 한 줄인데 그 한 줄을 찾는 길이 목록 아이콘 안쪽에 숨어 있었습니다.

두 게임 모두 지금은 심사 대기입니다. 통과했는지는 이 글을 쓰는 시점에 모릅니다. 결과가 나오면 이 글에 덧붙이겠습니다.

FAQ

갤럭시 스토어 기본 언어는 무엇으로 해야 하나요?

두 나라 이상에 판매하면 기본 이름과 설명이 영어여야 합니다. 앱을 처음 등록할 때 기본 언어를 English 로 고르고 한국어는 언어 추가로 붙이는 편이 안전합니다.

Test Confirmation Rejected 는 무슨 뜻인가요?

심사가 반려됐다는 상태입니다. 사유는 목록의 리뷰 칸 아이콘을 눌러 첨부 파일(Report.html)을 열어야 읽힙니다. 앱 문제가 아니라 이름·설명 같은 등록 정보 문제일 수도 있어요.

반려된 뒤 같은 APK 로 다시 낼 수 있나요?

됩니다. 리뷰 실패 상태의 파일은 그대로 못 내므로 파일 탭에서 그 APK 를 지우고 같은 파일을 다시 추가하면 버전 번호 그대로 통과했습니다.

스크린샷도 영어로 따로 올려야 하나요?

네. 스크린샷은 언어마다 따로 올립니다. 기본 언어를 영어로 바꾸면 영어 칸에 4~8장을 새로 채워야 했어요(나는 6장).
