三星 Galaxy Store 退回我的遊戲，原因是「預設語言」欄位

Justin Lee, Dumb Game Lab · 2026-11-15

要把 App 賣到兩個以上的國家，三星 Galaxy Store 要求預設名稱和說明必須是英文。我把預設語言設成韓文，送出《只活一次：人生模擬器》，11月11日收到 Test Confirmation Rejected。在那之前，我已經歷了四次賣家審核，還踩過首次提交的年齡分級欄位陷阱。後來我補上英文名稱、說明和 6張 截圖重新送審；另一款設定相同的遊戲，我則直接取消審核，改成英文預設再送。

賣家審核申請四次，接著才能提交

在 Galaxy Store 上架 App 之前，要先通過賣家審核。我 10月21日 第一次申請轉為付費賣家，11月10日 第4次申請 才通過。每次被退回的原因都一樣：商業登記資料（D-U-N-S）的檔案裡看不到網站。

通過後我馬上上傳了《只活一次：人生模擬器》1.0.7。這一步也有個坑：畫面上有兩個選年齡限制的欄位，其中一個是給中國用的隱藏欄位，填在那裡的話，儲存會顯示「完成」，提交卻被擋下。我找到真正的欄位、填入 12+，清單上才跳出 Ready for Review。

退回原因：預設名稱和說明不是英文

提交之後，狀態變成了 Test Confirmation Rejected。退回原因要點開清單裡審核欄的圖示，打開附件（Report.html）才看得到。只有一行：「[Metadata] Default description and application name (Not in English)」。

它不是說 App 會當機，也不是說違反政策。我建立 App 時把預設語言選成 Korean，而銷售國家有兩個以上，所以預設名稱和說明必須是英文。我原本以為韓文遊戲的預設就該是韓文，這個想法是錯的。

  • 狀態：Test Confirmation Rejected
  • 原因：Default description and application name (Not in English)
  • 根源：預設語言欄位是 Korean

修正方式：預設語言改英文，韓文用「新增語言」補上

修正順序是這樣：先在新增語言裡加入 English，把預設語言改成 English，再用英文重寫名稱、說明和一句話簡介。英文名稱我取為「One Life: Reborn Simulator」，韓文則留作額外語言。

截圖是每個語言各自獨立的，所以我在英文欄位重新上傳了 6張 英文畫面。最後，「審核失敗」狀態下的 App 檔案無法原樣再送，我就在檔案分頁刪掉同一個 APK 再重新加入。版本號碼不用改，照樣通過了。

設定相同的另一款遊戲，我先動手改了

當時還有另一款遊戲在審核中。Trigger Trio 的預設語言也是韓文，一定會因為同樣的原因被退，所以我沒等結果，直接取消審核，改成英文預設再送。取消之後狀態會回到「登錄中」，就可以修改了。

上架流程文件的第一行，我也從「預設語言 Korean」改成了「English」（#6643）。往後的遊戲，一開始建立就用英文。

一個看了會想笑的原因，花了我兩天

賣家審核花了3週，年齡欄位的坑踩了一次，語言欄位則花了兩天。打開退回通知之前，我一直懷疑是 App 檔案太大或權限有問題。原因明明只有一行，但要找到那一行，得點進清單圖示的裡面。

兩款遊戲現在都在等審核。截至寫這篇文章時，我還不知道有沒有通過。結果出來後，我會補在這篇文章裡。

FAQ

Galaxy Store 的預設語言要選什麼？

如果銷售到兩個以上的國家，預設名稱和說明必須是英文。第一次建立 App 時就把預設語言選成 English，再用新增語言補上韓文，比較保險。

Test Confirmation Rejected 是什麼意思？

表示審核被退回。原因要點開清單裡審核欄的圖示，打開附件（Report.html）才讀得到。問題也可能不在 App 本身，而是名稱、說明這類上架資訊。

被退回之後，可以用同一個 APK 重新送審嗎？

可以。審核失敗狀態下的檔案無法原樣再送，所以要到檔案分頁刪掉那個 APK，再把同一個檔案重新加入，版本號碼不變也通過了。

截圖也要另外上傳英文版嗎？

要。截圖是每個語言各自上傳的。預設語言改成英文後，英文欄位得重新補上 4～8張 截圖（我補了 6張）。
