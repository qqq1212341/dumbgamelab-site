Galaxy Store ปฏิเสธเกมของผม เพราะ «ช่องภาษาเริ่มต้น»

Justin Lee, Dumb Game Lab · 2026-11-15

ชีวิตเดียวเท่านั้น

Google Playเล่นบนเบราว์เซอร์

ถ้าลงแอปบน Samsung Galaxy Store แล้วขายมากกว่าหนึ่งประเทศ ชื่อและคำอธิบายเริ่มต้นต้องเป็นภาษาอังกฤษ ผมตั้งภาษาเริ่มต้นเป็นภาษาเกาหลีแล้วส่ง «ชีวิตเดียว: เกมจำลองชีวิต» ไป พอวันที่ 11 พ.ย. ก็ได้ Test Confirmation Rejected ทั้งที่ผ่านการยื่นขอเป็นผู้ขายแบบเสียเงิน 4 ครั้ง และกับดักช่องอายุตอนส่งครั้งแรกมาแล้ว ผมเลยส่งใหม่ด้วยชื่อ คำอธิบาย และภาพหน้าจอภาษาอังกฤษ 6 ภาพ ส่วนเกมอีกเกมที่ตั้งค่าเหมือนกัน ผมยกเลิกการตรวจสอบแล้วส่งใหม่โดยใช้ภาษาอังกฤษเป็นค่าเริ่มต้น

สารบัญ

  1. ยื่นขอเป็นผู้ขาย 4 ครั้ง แล้วค่อยส่งเกม
  2. สาเหตุที่ถูกปฏิเสธ: ชื่อและคำอธิบายเริ่มต้นไม่ใช่ภาษาอังกฤษ
  3. วิธีแก้: เปลี่ยนภาษาเริ่มต้นเป็นอังกฤษ แล้วเพิ่มภาษาเกาหลีทีหลัง
  4. เกมอีกเกมที่ตั้งค่าเหมือนกัน ผมแก้ก่อนโดนปฏิเสธ
  5. เสียเวลาไปสองวันกับเหตุผลที่ใครอ่านก็ขำ

ยื่นขอเป็นผู้ขาย 4 ครั้ง แล้วค่อยส่งเกม

Galaxy Store ให้ผ่านการอนุมัติผู้ขายก่อนถึงจะอัปโหลดแอปได้ ผมยื่นขอเปลี่ยนเป็นผู้ขายแบบเสียเงินครั้งแรกวันที่ 21 ต.ค. และได้รับอนุมัติในการยื่นครั้งที่ 4 วันที่ 10 พ.ย. ทุกครั้งที่โดนปฏิเสธ เหตุผลเดียวกันหมด คือโปรไฟล์หมายเลขธุรกิจ (D-U-N-S) มองไม่เห็นเว็บไซต์

พออนุมัติปุ๊บ ผมก็อัปโหลดชีวิตเดียว: เกมจำลองชีวิต เวอร์ชัน 1.0.7 ทันที ขั้นนี้ก็มีกับดักอีกอย่าง ช่องเลือกอายุผู้เล่นมีสองช่องบนหน้าจอ และหนึ่งในนั้นเป็นช่องซ่อนสำหรับประเทศจีน ถ้ากรอกช่องนั้น ระบบจะขึ้นว่าบันทึกเสร็จ แต่ส่งไม่ได้ ผมหาช่องจริงเจอแล้วใส่ 12+ รายการถึงขึ้นสถานะ Ready for Review

สาเหตุที่ถูกปฏิเสธ: ชื่อและคำอธิบายเริ่มต้นไม่ใช่ภาษาอังกฤษ

หลังส่ง สถานะเปลี่ยนเป็น Test Confirmation Rejected เหตุผลต้องกดไอคอนในช่องรีวิวของรายการ แล้วเปิดไฟล์แนบ (Report.html) ถึงจะอ่านได้ มีบรรทัดเดียว «[Metadata] Default description and application name (Not in English)»

ไม่ได้บอกว่าแอปพัง หรือผิดนโยบายอะไรเลย ตอนสร้างแอป ผมเลือกภาษาเริ่มต้นเป็น Korean และเพราะขายมากกว่าหนึ่งประเทศ ชื่อกับคำอธิบายเริ่มต้นจึงต้องเป็นภาษาอังกฤษ ที่ผมคิดว่าเกมเกาหลีก็ต้องใช้ภาษาเกาหลีเป็นค่าเริ่มต้นนั้น ผมคิดผิดเอง

  • สถานะ: Test Confirmation Rejected
  • เหตุผล: Default description and application name (Not in English)
  • สาเหตุ: ช่องภาษาเริ่มต้นเป็น Korean

วิธีแก้: เปลี่ยนภาษาเริ่มต้นเป็นอังกฤษ แล้วเพิ่มภาษาเกาหลีทีหลัง

ลำดับที่แก้คือ เพิ่มภาษา English ก่อน แล้วเปลี่ยนภาษาเริ่มต้นเป็น English จากนั้นเขียนชื่อ คำอธิบาย และคำโปรยสั้นๆ ใหม่เป็นภาษาอังกฤษ ชื่อภาษาอังกฤษที่ผมใช้คือ «One Life: Reborn Simulator» ส่วนภาษาเกาหลีเก็บไว้เป็นภาษาที่เพิ่มเข้ามา

ภาพหน้าจอต้องอัปโหลดแยกตามภาษา ผมจึงอัปโหลดภาพหน้าจอภาษาอังกฤษชุดใหม่ 6 ภาพลงช่อง English สุดท้าย ไฟล์แอปที่อยู่ในสถานะรีวิวไม่ผ่านจะส่งซ้ำตรงๆ ไม่ได้ ผมเลยลบ APK ตัวเดิมในแท็บไฟล์แล้วเพิ่มกลับเข้าไปใหม่ หมายเลขเวอร์ชันเดิมก็ผ่านได้

เกมอีกเกมที่ตั้งค่าเหมือนกัน ผมแก้ก่อนโดนปฏิเสธ

ตอนนั้นมีอีกเกมหนึ่งที่อยู่ระหว่างการตรวจสอบ คือ Trigger Trio ซึ่งตั้งภาษาเริ่มต้นเป็นภาษาเกาหลีเหมือนกัน เดาได้เลยว่าต้องโดนปฏิเสธด้วยเหตุผลเดียวกัน ผมเลยไม่รอผล ยกเลิกการตรวจสอบ เปลี่ยนเป็นภาษาอังกฤษเป็นค่าเริ่มต้น แล้วส่งใหม่ พอยกเลิก สถานะกลับไปเป็นกำลังลงทะเบียน จึงแก้ไขได้

ผมแก้บรรทัดแรกของเอกสารขั้นตอนการลงทะเบียนจาก «ภาษาเริ่มต้น Korean» เป็น «English» ด้วย (#6643) เกมถัดไปจะเริ่มต้นด้วยภาษาอังกฤษตั้งแต่ตอนสร้าง

เสียเวลาไปสองวันกับเหตุผลที่ใครอ่านก็ขำ

การอนุมัติผู้ขายใช้เวลา 3 สัปดาห์ กับดักช่องอายุหนึ่งครั้ง และช่องภาษาอีกสองวัน ก่อนจะเปิดอีเมลแจ้งปฏิเสธ ผมสงสัยว่าเป็นเรื่องขนาดแอปหรือสิทธิ์การเข้าถึง ต้นเหตุมีบรรทัดเดียว แต่ทางไปหามันซ่อนอยู่หลังไอคอนในรายการ

ตอนนี้ทั้งสองเกมรอการตรวจสอบอยู่ ขณะที่เขียนบทความนี้ผมยังไม่รู้ว่าผ่านหรือไม่ ถ้ามีผล ผมจะมาเพิ่มในบทความนี้

FAQ

ลงเกมบน Galaxy Store ควรตั้งภาษาเริ่มต้นเป็นภาษาอะไร

ถ้าขายมากกว่าหนึ่งประเทศ ชื่อและคำอธิบายเริ่มต้นต้องเป็นภาษาอังกฤษ ตอนลงทะเบียนแอปครั้งแรก ให้เลือกภาษาเริ่มต้นเป็น English แล้วเพิ่มภาษาเกาหลีเป็นภาษาที่เพิ่มเข้ามา จะปลอดภัยกว่า

Test Confirmation Rejected แปลว่าอะไร

แปลว่าการตรวจสอบไม่ผ่าน เหตุผลต้องกดไอคอนในช่องรีวิวของรายการแล้วเปิดไฟล์แนบ (Report.html) ถึงจะอ่านได้ บางครั้งไม่ใช่ปัญหาของตัวแอป แต่เป็นข้อมูลลงทะเบียนอย่างชื่อหรือคำอธิบาย

หลังถูกปฏิเสธ ส่ง APK ตัวเดิมซ้ำได้ไหม

ได้ ไฟล์ที่อยู่ในสถานะรีวิวไม่ผ่านจะส่งซ้ำตรงๆ ไม่ได้ ให้ลบ APK ตัวนั้นในแท็บไฟล์แล้วเพิ่มไฟล์เดิมกลับเข้าไป หมายเลขเวอร์ชันเดิมก็ผ่านได้

ต้องอัปโหลดภาพหน้าจอภาษาอังกฤษแยกด้วยไหม

ต้องอัปโหลด ภาพหน้าจออัปโหลดแยกตามภาษา พอเปลี่ยนภาษาเริ่มต้นเป็นอังกฤษ ผมต้องใส่ภาพชุดใหม่ 4-8 ภาพในช่อง English (ผมใช้ 6 ภาพ)
