ผมปิดไป 78 ใบ แต่รายการยังเท่าเดิม

Justin Lee, Dumb Game Lab · 2026-11-13

วันที่ 31 ตุลาคม ผมปิดตั๋วไป 78 ใบ แต่มีตั๋วใหม่เปิดขึ้น 101 ใบ จำนวนที่เหลือจึงเป็น 334 จากเมื่อวาน 335 แทบไม่ขยับ ตั๋วใหม่ส่วนใหญ่ถูกเปิดโดยตัวเก็บ crash และระบบตรวจอัตโนมัติ จำนวนที่ปิดไม่ใช่ปริมาณงาน ต้องนับจำนวนที่เปิดใหม่และเหตุผลที่เปิดไปพร้อมกัน ถึงจะเห็นว่ารายการลดลงจริงหรือไม่

สารบัญ

  1. 31 ตุลาคม: merge 221 ครั้ง แต่รายการอยู่ที่เดิม
  2. วันนั้นผมโดนติมาว่าอะไร
  3. ตั๋วใหม่ส่วนใหญ่ไม่ใช่ผมที่เป็นคนเปิด
  4. จุดที่ผมตัดสินพลาด: เอาจำนวนที่ปิดมานับเป็นปริมาณงาน
  5. สิ่งที่ผมแก้คือบรรทัดตัวเลขบรรทัดเดียว

31 ตุลาคม: merge 221 ครั้ง แต่รายการอยู่ที่เดิม

บรรทัดตัวเลขในบันทึกวันนั้นเป็นแบบนี้ เซสชัน 294, merge 221, ตั๋วใหม่ 101, แก้เสร็จ 78, ตั๋วที่เหลือ 334 ส่วนตั๋วที่เหลือของเมื่อวานคือ 335

วันนั้นทำงานเยอะจริง ผมรวบงานเตรียมปล่อย Ppijukland ไว้ในวันเดียว มีทั้งเอกสารแผนเกม ชื่อในสโตร์ เปลือกแอปแอนดรอยด์ การลดช่องที่ขาดในสมุดรายการองค์ประกอบ 36 ช่องให้เหลือ 0 และการแปลสิบภาษา แต่รายการไม่ลดแม้แต่ช่องเดียว

วันนั้นผมโดนติมาว่าอะไร

ช่วงเช้ามีคนบอกผมว่า «คุณชอบเปิดตั๋วแล้วเลื่อนไปเรื่อย ๆ» แล้ววันนั้นก็มีตั๋วใหม่เปิดขึ้น 101 ใบ ตัวเลขตอบคำติเตือนนั้นได้ตรงพอดี

ผมปิดไป 78 ใบ ถือว่าได้ทำงานจริง แต่ถ้าคิดตามลำดับ เปิด 101 ปิด 78 รายการควรเพิ่มขึ้น 23 ใบ ทว่าจำนวนที่เหลือกลับลดลงหนึ่งใบ ในบันทึกไม่มีบรรทัดอธิบายช่วงห่างตรงนี้ ผมไม่ได้ตรวจสอบว่ามีตั๋วกี่ใบที่ถูกปิดไปจากทางอื่น

ตั๋วใหม่ส่วนใหญ่ไม่ใช่ผมที่เป็นคนเปิด

สาเหตุที่ผมจดไว้ในบันทึกมีสองอย่าง อย่างแรกคือตั๋วที่ตัวเก็บ crash เปิดให้เองทุกครั้งที่มีข้อผิดพลาด อย่างที่สองคือตั๋วที่ระบบตรวจอัตโนมัติเปิดโดยใส่ชื่อกฎกำกับ สองอย่างนี้เป็นสัดส่วนใหญ่ของตั๋วใหม่

ตั๋วที่ผมเขียนเองว่า «อันนี้ต้องทำ» พอปิดก็คืองานหนึ่งอย่างเสร็จ แต่ตั๋วที่เครื่องเปิด ถ้าข้อผิดพลาดเดิมเข้ามาอีก มันก็เปิดซ้ำอีก ปิดเร็วแค่ไหนก็ตาม ถ้าเปิดเร็วกว่า รายการก็ยังอยู่เท่าเดิม

จุดที่ผมตัดสินพลาด: เอาจำนวนที่ปิดมานับเป็นปริมาณงาน

พอจบวัน ตัวเลขที่เด้งเข้าตาก่อนคือ «วันนี้ปิดไปกี่ใบ» 78 ใบอ่านแล้วเหมือนทำงานไปเยอะ

แต่ขนาดของรายการไม่ได้ขึ้นกับจำนวนที่ปิด มันขึ้นกับส่วนต่างระหว่างจำนวนที่ปิดกับจำนวนที่เปิดใหม่ ถ้าไม่นับจำนวนที่เปิดไปด้วย ยิ่งทำหนักก็ยิ่งเข้าใจผิดว่างานกำลังลดลง

  • ดูแค่จำนวนที่ปิด ได้ 78 ใบ วันนี้ดูดี
  • ดูจำนวนที่เปิดด้วย ได้ 101 ใบ รายการเพิ่มขึ้นในวันนี้
  • ดูเหตุผลที่เปิดด้วย จะเห็นว่างานที่คนเขียนกับงานที่เครื่องเปิดปนกันอยู่ จึงนับรวมเป็นเลขเดียวไม่ได้

สิ่งที่ผมแก้คือบรรทัดตัวเลขบรรทัดเดียว

งานของวันนั้นง่ายมาก ผมเพิ่มจำนวนตั๋วใหม่ จำนวนที่แก้เสร็จ และจำนวนที่เหลือ ลงในบรรทัดตัวเลขบนสุดของบันทึก (#4504) ตั้งแต่วันถัดไปจะได้ดูแค่จำนวนที่ปิดแล้วอุ่นใจไม่ได้อีก

นี่ไม่ใช่การแก้ปัญหาใหญ่ การลดตั๋วที่เครื่องเปิด ผมยังไม่ได้ทำในวันนั้น ต้องเห็นตัวเลขก่อนถึงจะเลือกได้ว่าจะลดตรงไหน ผมจึงทำให้มองเห็นก่อนอย่างเดียว
