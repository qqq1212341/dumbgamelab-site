オフラインで遊べる放置系タイクーン、ストア表記で選んだ8本

Justin Lee, Dumb Game Lab · 2026-10-16

「オフライン」には2つの意味があります。アプリを閉じている間もお金が貯まるという意味と、ネット接続なしで起動できるという意味です。Google Playに「Offline」タグが付いているのはIdle Miner Tycoon、Egg, Inc.、Idle Bank Tycoon、Game Dev Storyで、AdVenture Capitalistはストアの説明にインターネット接続が必要と書かれています。買い切りで遊べるのはGame Dev StoryとGame Dev Tycoonです。

選び方

放置系タイクーンのうち、Google Playとアプリストアに実際に出ていて、インストール数やレビューが積み上がっているものを選びました。1本ずつ丸1日遊んだ評価ではなく、2026年10月16日にGoogle Play（米国ストア、英語）の詳細ページ、アプリストアの検索結果、Steamのページで確認した表記をまとめた比較です。

オフラインの欄は2つに分けて書きました。1つはGoogle Playの詳細ページに付く「Offline」タグ、もう1つはストアの説明文にある記述です。どちらもなければ「表記なし」としています。価格は米国ストアの定価です。

「オフライン」が2つの意味で使われる理由

放置ゲームでオフラインといえば、たいていは「席を外している間もお金が貯まる」という意味です。ネットなしで起動できるかどうかは、別に確かめる必要があります。ストアの説明はこの2つを混ぜて書くことが多いので、ネットのない場所で遊ぶ人が説明文だけで選ぶと外しやすくなります。

検索のされ方も分かれます。日本語では「放置ゲーム おすすめ オフライン」と「オフライン 経営ゲーム」が候補に出ます。インドネシア語では「apakah game idle theme park tycoon offline」のように、ゲーム名を入れてオフラインで遊べるかを尋ねる検索があります。下の表は、その疑問にストアの表記で答える順番になっています。

タグが付いた放置系：Idle Miner Tycoon、Egg, Inc.、Idle Bank Tycoon

Idle Miner Tycoonは1億インストール以上、レビュー約586万件で評価4.5と、この表でいちばん大きなゲームです。説明には「オフラインでも鉱山を動かせる」という文が何度も出てきます。ただ、この文がネットなしで起動できるという意味なのか、閉じている間にお金が貯まるという意味なのかは、説明だけでは判断できません。

Egg, Inc.は1,000万インストール以上で評価4.7、説明にオフラインの記述はなく、Google Playのタグだけが付いています。Idle Bank Tycoonは説明に「オフライン銀行シミュレーター」とあり、オフライン中も従業員が現金を稼ぐという文があります。3本とも無料で、広告とアプリ内課金が付きます。

インターネットが必要と書かれたもの：AdVenture Capitalist

AdVenture Capitalistは1,000万インストール以上、レビュー約164万件で評価4.5という、元祖格の放置ゲームです。説明には自動化によってオフライン収益を得られるという文がありますが、同じ説明に「プレイにはインターネット接続が必要」とも書かれています。Google Playの「Offline」タグも付いていません。飛行機や地下鉄の中で遊ぶゲームを探しているなら、説明のとおりこのゲームは外すことになります。

買い切りで遊べる：Game Dev Story、Game Dev Tycoon

厳密には放置系ではなく、時間をゆっくり使う経営ゲームですが、オフラインで探す人が一緒に見ることの多い2本です。Game Dev StoryはGoogle Playで$4.49（アプリストアは$4.99）、「Offline」タグが付いていて、インストール100万以上、評価4.7です。Game Dev Tycoonは$4.99で、ストアの説明に広告もアプリ内購入もないと書かれており、Steamでは$9.99でWindows、Mac、Linuxに対応しています。オフラインの記述とタグは、このゲームには見当たりませんでした。

2本とも、お金を払えば広告なしで最後まで遊べる点が、無料の放置ゲームとの大きな違いです。

オフライン進行はあるがタグはない：Idle Theme Park Tycoon

Idle Theme Park Tycoonは1,000万インストール以上で評価4.1、説明の機能一覧に「オフライン進行」があります。自分で遊んでいない間もお金が貯まるという文はありますが、Google Playの「Offline」タグはありません。インドネシア語の検索のように、このゲームはオフラインで遊べるのかと聞かれたら、ストアの表記では「閉じている間の進行はある、ネットなしで起動できるかは表記なし」が正確な答えです。

ネットカフェ育成：できることと弱点

Dumb Game Labが作ったネットカフェ育成は、路地裏のネットカフェを引き継いで全国1位まで育てる放置系経営ゲームです。ストアの説明にオフラインでプレイできると書いてあり、バイトを雇っておけばアプリを閉じている間も店が回ります。6席で開店し、カップ麺の調理台と自販機を席の近くに置くほどよく売れます。1日は2分で、最大3倍速です。

弱点ははっきりしています。新作なのでGoogle Playのインストールは100以上、評価はまだなく、上の表の他のゲームと違ってGoogle Playの「Offline」タグも付いていません。路地裏から全国まで6段階なので終わりがあり、Idle Miner TycoonやGame Dev Tycoonのように長く回したり深く掘り下げたりする楽しみはありません。進行状況は端末にだけ保存されるため、機種変更のときは移す方法を別に用意する必要があります。精算時に広告を見るとその日に稼いだお金が2倍になり、広告を見なくても進行はできます。

どのゲームが合うか

ネットのない場所で遊ぶなら、Google Playのタグとストアの記述が両方そろっているものから見て、最後に機内モードで一度起動してみるのがいちばん確実です。この記事の表記は、ストアの説明が変わると変わることがあります。

  • 長く回せる大型の放置ゲーム：Idle Miner Tycoon、Egg, Inc.
  • 銀行経営がテーマ：Idle Bank Tycoon
  • インターネットが必要と書かれた放置ゲーム：AdVenture Capitalist（オフライン用途では除外）
  • 買い切りで最後まで：Game Dev Story、Game Dev Tycoon
  • 短く遊べるスマホ向けの放置ゲーム、オフライン表記あり：ネットカフェ育成

FAQ

放置系タイクーンはオフラインで遊べますか？

ゲームによって違います。Google Playの「Offline」タグが付いているのはIdle Miner Tycoon、Egg, Inc.、Idle Bank Tycoon、Game Dev Storyで、AdVenture Capitalistはストアの説明にインターネット接続が必要と書かれています。

アプリを閉じていてもお金は貯まりますか？

Idle Theme Park Tycoon、Idle Bank Tycoon、ネットカフェ育成は、ストアの説明に閉じている間も進行すると書かれています。この記述は、ネットなしで起動できるという意味ではありません。

Wi-Fiなしで遊べるタイクーンゲームはどれがいいですか？

Google Playの「Offline」タグが付いたIdle Miner Tycoon、Egg, Inc.、Idle Bank Tycoon、Game Dev Storyを先に見てください。使い始める前に、機内モードで一度起動してみると確実です。

広告なしで、買い切りで遊べるタイクーンゲームはありますか？

Game Dev StoryはGoogle Playで$4.49、Game Dev Tycoonは$4.99です。Game Dev Tycoonは、ストアの説明に広告もアプリ内購入もないと書かれています。
