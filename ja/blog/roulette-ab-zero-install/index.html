再生は1,269回あったのに、インストールは1件もありませんでした

Justin Lee, Dumb Game Lab · 2026-11-11

ルーレットアプリの宣伝ショート動画6本(アプリ画面の録画3本、チチのアニメーション3本)をYouTube・TikTok・Instagramに投稿し、7日間を計測しました。再生数は画面録画が681回、アニメーションが588回で、ストアのリンクやUTMで確認できたインストールはどちらも0件でした。勝った形式はなく、ショート動画はインストールの入口にならないということだけが数字で残りました。

何を試したか

ルーレットアプリ「チチの決定ルーレット」をGoogle Playに出したのは10月17日です。項目を入れて回すと、猫の社長チチが結果を発表するだけのシンプルなツールです。知ってもらう手段がショート動画しかなく、どんな形が効くかもわからなかったので、2種類に分けました。

Aは実際のアプリ画面を録画して、最初の3秒に「ランチ何にする?」のような問いかけの字幕を重ねた動画です。Bはチチ自身がルーレットを回すアニメーションで、最後の2秒だけアプリ画面を見せます。2本はテーマも結果も同じで、同じ日の同じ時刻に投稿しました。

10月22日から3日間、夜7時に1組ずつ、ランチのメニュー・今日の会計は誰か・罰ゲーム決めの3つのテーマを、YouTubeショート、TikTok、Instagramリールに投稿しました。作ってあった残り2組は、アカウントのコンセプトに合わないので出していません。

7日後の数字

判定は11月2日に出しました。再生数は、YouTubeのデータAPI、Instagramのインサイト、TikTokの公開ページの再生回数を読みました。インストールは、Play ConsoleのUTMキャンペーンの表と、アプリのGAの初回起動の記録で数えました。

勝ち負けはついたが、合わせても勝者はいなかった

ペア1はAが222対123、ペア2はBが270対219、ペア3はAが240対195で勝ちました。Aの2勝1敗です。最初に決めた基準は「5組のうち4組以上が同じ側」でしたが、3組しか出ず、その3組も片方に偏りませんでした。

そのため判定は「勝者なし」です。ただしBはチチの場面を別に作り、Aの録画まで入るので、制作費が大きくなります。再生が同じ水準なら安いほうを基本にするのが筋なので、これからのショート動画はAで出します。

インストールが0だった理由を調べた

7日間で、Playのストア掲載ページの訪問者のうち流入元がわかったのは「その他」の2人で、こちらがつけたUTMの名前で来た人はいませんでした。同じ期間のアプリの初回起動33件は、ほとんどが流入元なし(直接訪問)の30件と、Playの自然検索の3件でした。

限界もあります。リンクを押せる場所は、YouTubeの概要欄と固定コメントだけでした。TikTokとInstagramのキャプションのリンクは押せないので入れていません。再生1,269回のうち、リンクの前に立った可能性があるのはYouTubeの495回だけです。InstagramとTikTokの再生が「プロフィールを見て、ストアで検索して」インストールにつながっていたなら、この表では「直接訪問」に混ざって見えているはずです。

それでも結論は同じです。直接訪問の30件がショート動画のおかげかどうかを分ける方法はなく、分けられる欄(UTM)はすべて0でした。ショート動画の再生数は、再生が始まるたびに増える数字なので(YouTubeは2025年3月31日から最低視聴時間なしで数えています)、1,269回がそのまま1,269人の関心ではありません。

そのあとにやったこと

ショート動画で小さなアプリを広める実験は、11月3日にやめました。アプリを出してから17日間のインストールは41件で、そのうちショート動画から来たと確認できたのは0件です。流入元は直接訪問が36件、Playの自然流入が5件でした。一緒に作ろうとしていたくじ引きと真実か挑戦かのアプリは、作っていません。

ルーレットアプリは下げず、そのまま置いておきます。維持費がかからないことと、インストールが入る道がPlayの自然検索だと数字で確かめられたためです。次に手を入れるのは動画ではなく、ストアの名前とキーワードです。空いている検索語を調べたところ、インドネシアの「dadu」、ブラジルの「sorteio de times」、日本の「コイントス」のような言葉には大手のアプリがなく、これをルーレットの中のモード(サイコロ・チーム分け・コイン)として入れるほうが、新しいアプリを作るより安く済みます。

次にショート動画を出すときに守ること

数字が教えてくれたことは多くありませんが、ひとつははっきりしています。再生数とインストール数は別の帳簿なので、再生が増えてもインストールの欄が空なら、その動画は数字を作っただけです。

  • インストールを見たいなら、まずリンクを押せる場所を作る。押せないキャプションには期待をかけない
  • 再生1,000回あたりのインストールを動画ごとに書く。以前集めた目安は0.5件から5件で、今回はそれを下回った
  • 勝者がいなければ、形式をこれ以上比べず、安い形式で行く
  • 小さなアプリのインストールの入口はストア検索。動画より先に名前とキーワードを直す

FAQ

ショート動画の再生数が多いと、アプリのインストールも増えますか?

今回の実験では増えませんでした。ルーレットアプリのショート動画6本は7日間で1,269回再生されましたが、UTMのリンクにもPlay ConsoleにもGAにも、ショート動画から来たインストールは0件でした。再生とインストールは別々に測る必要があります。

ショート動画からのアプリインストールは、どうやって測りますか?

概要欄や固定コメントのリンクにUTM(utm_source、utm_campaign)をつけて、Play ConsoleのUTMキャンペーンの表とGAの初回ユーザーの参照元で同じ名前を探します。キャプションのリンクが押せないTikTokとInstagramは、この方法では測れません。

アプリ画面の録画とキャラクターのアニメーションでは、どちらがいいですか?

再生数は、アプリ画面の録画が1本あたり227回、アニメーションが196回とやや多かったものの、3組のうち1組はアニメーションが勝ちました。インストールはどちらも0件で優劣はつかず、制作費がかからない画面録画を基本にすることにしました。

ショート動画はアプリの宣伝に役立たないということですか?

そこまでは言えません。1つのアプリ、6本、7日間の結果で、リンクが押せる場所もYouTubeだけでした。このアプリではインストールにつながらなかった、というところまでしか言えません。
