Galaxy Store がゲームをリジェクトした理由は「デフォルト言語」の欄だった

Justin Lee, Dumb Game Lab · 2026-11-15

一度きりの人生

Google Playブラウザで遊ぶ

サムスンの Galaxy Store で2か国以上に販売するアプリは、デフォルトのアプリ名と説明が英語でなければなりません。私はデフォルト言語を韓国語にして「一度きりの人生」を申請し、11月11日に Test Confirmation Rejected を受け取りました。有料販売者の承認に4回、初回申請の年齢設定の落とし穴を越えたあとでした。英語の名前・説明・スクリーンショット6枚で出し直し、同じ設定だった別のゲーム1本は審査を取り下げて、英語デフォルトで出し直しました。

販売者承認に4回、そのあとで申請

Galaxy Store では、アプリを登録する前に販売者承認を受ける必要があります。私は10月21日に有料販売者への切り替えを初めて申請し、11月10日の4回目の申請でようやく承認されました。リジェクトの理由は毎回、事業者番号(D-U-N-S)のプロフィールにウェブサイトが表示されないというものでした。

承認が下りてすぐに、一度きりの人生 1.0.7 をアップロードしました。この段階にも落とし穴がひとつありました。年齢制限を選ぶ欄が画面に2つあり、片方は中国向けの隠れた欄でした。そちらに値を入れると、保存は「完了」になるのに申請が通りません。本当の欄を見つけて12+を入れると、ようやく一覧に Ready for Review と表示されました。

リジェクト理由:デフォルトの名前と説明が英語ではない

申請後、ステータスが Test Confirmation Rejected に変わりました。理由は、一覧のレビュー欄のアイコンを押して添付ファイル(Report.html)を開かないと読めません。書かれていたのは1行でした。«[Metadata] Default description and application name (Not in English)»。

アプリが落ちるとか、ポリシーに違反しているという話ではありませんでした。私はアプリを作るときにデフォルト言語を Korean にしていて、販売国が2か所以上あるため、デフォルトの名前と説明は英語でなければならなかったのです。韓国語のゲームだから韓国語がデフォルト、という私の思い込みが間違いでした。

  • ステータス:Test Confirmation Rejected
  • 理由:Default description and application name (Not in English)
  • 原因:デフォルト言語の欄が Korean

直したこと:デフォルト言語を英語に、韓国語は「言語を追加」で

直す手順はこうです。言語の追加で English を入れ、デフォルト言語を English に切り替え、名前と説明とひと言紹介を英語で書き直します。英語名は «One Life: Reborn Simulator» にしました。韓国語は追加言語として残しています。

スクリーンショットは言語ごとに別です。そのため、英語の欄に英語画面を6枚、新しくアップロードしました。最後に、「レビュー失敗」状態のアプリファイルはそのままでは再申請できないので、ファイルタブで同じ APK を削除してから追加し直しました。バージョン番号はそのままで通りました。

同じ設定だった別のゲームは先に直した

そのとき審査中のゲームがもう1本ありました。Trigger Trioも、デフォルト言語が韓国語でした。同じ理由でリジェクトされるのは目に見えていたので、結果を待たずに審査を取り下げ、英語デフォルトに変えて出し直しました。取り下げると状態が登録中に戻るので、修正できました。

登録手順のドキュメントの1行目も、「デフォルト言語 Korean」から「English」に直しました(#6643)。次のゲームからは、最初に作る時点で英語で始めます。

人が読んだら笑ってしまう理由で2日かかった

販売者承認に3週間、年齢欄の落とし穴にひとつ、言語欄に2日でした。リジェクトのメールを開くまでは、アプリの容量や権限の問題を疑っていました。原文は1行なのに、その1行にたどり着く道が一覧のアイコンの奥に隠れていました。

2本とも、いまは審査待ちです。通ったかどうかは、この記事を書いている時点ではわかりません。結果が出たら、この記事に追記します。

FAQ

Galaxy Store のデフォルト言語は何にすればいいですか?

2か国以上で販売する場合、デフォルトの名前と説明は英語である必要があります。アプリを最初に登録するときにデフォルト言語を English にして、韓国語は言語の追加で足す形が安全です。

Test Confirmation Rejected とはどういう意味ですか?

審査がリジェクトされたという状態です。理由は、一覧のレビュー欄のアイコンを押して添付ファイル(Report.html)を開くと読めます。アプリ自体ではなく、名前や説明といった登録情報の問題の場合もあります。

リジェクトされたあと、同じ APK で再申請できますか?

できます。レビュー失敗状態のファイルはそのまま出せないので、ファイルタブでその APK を削除し、同じファイルを追加し直すと、バージョン番号そのままで通りました。

スクリーンショットも英語で別にアップロードする必要がありますか?

はい。スクリーンショットは言語ごとに別にアップロードします。デフォルト言語を英語に変えたら、英語の欄に4〜8枚を新しく入れる必要がありました(私は6枚)。
